# 童映 Kindo — Unraid Community Applications

儿童语音媒体库 Kindo 的 Unraid 模板仓库（Community Applications 提交源）。

| 应用 | 说明 |
|---|---|
| [kindo-hub](https://github.com/Aaron-LiLei/kindo) | 核心服务：媒体库 / 规则 / AI 编排 / 家长后台（8090） |
| [kindo-asr](https://github.com/Aaron-LiLei/kindo) | 本地中文语音识别（离线 Paraformer，首启自动下载模型） |
| [kindo-tts](https://github.com/Aaron-LiLei/kindo) | 可选：家长声音克隆（不装自动回退系统语音） |

安装顺序：kindo-asr → kindo-hub →（可选）kindo-tts。
部署文档：https://github.com/Aaron-LiLei/kindo/blob/main/docs/DEPLOY.md
问题反馈：https://github.com/Aaron-LiLei/kindo/issues
